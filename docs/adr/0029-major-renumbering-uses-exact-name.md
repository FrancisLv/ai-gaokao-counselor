# 0029 · 专业重新编号时按映射组内精确名称匹配历史

- 状态：已接受
- 决策者：Francis
- 日期：2026-11-23

湖南招生计划中的专业代码是组内序号，可能跨年重新编号。中国海洋大学（212）当前“数学与应用数学”代码为 `51`，但同一 lineage 映射组在 2024/2023 使用代码 `47`。ADR-0021 同时要求代码与名称一致，导致数据库中真实存在的最低分和位次被错误显示为暂无数据。

决定把专业身份限定在组级 lineage 已确认的映射组内，并按精确专业名称匹配历史；历史代码与当前代码相同只作为选择重复同名记录时的 tie-break，不再作为硬门槛。同代码但名称不同的记录仍必须排除，不能恢复按代码单独拼接历史。

## 后果

- 专业重新编号但名称未变化时，可以回填历史最低分、最低位次和专业概率。
- 组级 lineage 仍是前置门禁；映射组不可信时不跨组搜索同名专业。
- 旧专业历史口径报告需要通过新迁移标记失效，避免继续展示缺少历史值的旧结果。
- 本决策部分替代 ADR-0021，不改变 ADR-0019 的专业概率独立性与 UNKNOWN 规则。
