# 0021 · 专业级历史匹配要求代码与名称同时一致

- 状态：部分被 ADR-0029 替代（专业代码变更场景改为组内精确名称匹配）
- 决策者：Francis

湖南院校专业组内的专业代码是组内序号，跨年可能被复用给完全不同的专业。真实数据中
哈尔滨工程大学（104）专业组当前代码 `19` 为“新能源材料与器件”，但 2024 年同代码为
“软件工程”、2022 年为“计算机类”。只按专业代码匹配会错误拼接不同专业的历史最低分、
位次和概率。

专业级历史参考必须同时满足当前专业代码与历史专业代码相同、当前专业名称与历史专业名称
严格一致（仅允许去除首尾空白）。名称缺失或不一致时排除该历史年份；剩余有效样本不足时
返回 UNKNOWN，不按名称相似度猜测或回退到组级概率。该约束补充 ADR-0019，不改变
`weighted_hit`、时间衰减和样本上限算法。
