# 0010 · 候选组内专业身份由报考年招生计划决定

- 状态：已接受（2026-11-20）
- 决策者：Francis

院校专业组的历史录取数据可以估计组级录取概率，但不能决定当年组内有哪些专业。
候选组内专业、专业代码、选科要求和计划信息一律读取报考年 `enrollment_plan`；
历史 `major_admission` 只回填同代码专业参考，并作为组概率窗口。

原因是专业代码会逐年调整。若继续用上一年历史专业再逐个匹配当年计划，一个仍在招生、
但更换了专业代码的组会被全部标成 `CANDIDATE_NOT_IN_PLAN`，资格门禁随后错误移除整组。
严格使用当年计划可以保留有效的组概率，同时不把历史专业冒充当前可报专业。

代价是当年计划中专业代码全为空、无法形成稳定身份的组必须排除，不能按名称猜回代码；
这类组需要 ETL 修正后重新发布 release。该保守取舍优先于扩大候选数量。
