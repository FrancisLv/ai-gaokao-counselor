# 0025 · 移除账户原始数据导出

- 状态：已接受
- 决策者：Francis
- 日期：2026-11-23

项目当前用于面试演示。账户原始数据 JSON 导出不属于高考志愿决策的核心能力，使用频率低，却同时增加用户界面、Gateway 权限校验、Orchestrator 数据组装、proto 契约和隐私测试的维护成本。我们决定从前端与 Gateway / Orchestrator 接口中完整移除该能力，保留账户删除、敏感资格同意撤销和报告 PDF 导出。

本决策部分替代 ADR-0023：该 ADR 的受控邀请注册、用户名密码、恢复码、Cookie 登录、账户删除和数据保留边界继续有效，只有“账户数据导出使用需再次输入密码的机器可读 JSON”部分被本 ADR 移除。

## 后果

- 删除 `POST /v1/account/export`、`ExportAccountData` 与 `ExportPrincipalData` RPC 及对应生成物。
- 用户仍可查看自己的报告与志愿表，并可通过账户删除终止服务、清理全部私有资料。
- 如未来确有数据可携带或合规需求，应作为独立范围重新评审，而不是恢复一个与核心流程无关的默认入口。
- 当前 `v1` 仅服务本仓库受控前端且未承诺外部兼容，因此直接在该版本移除；若未来出现外部消费者，应按 PRD §7.5 新增契约版本，不恢复已删除的旧路由。
