# 0015 · 区分无关问题、范围外问题与安全危机输入

- 状态：已接受
- 决策者：Francis

对话只对当前志愿域执行规划、解释和修订。与志愿填报无关的天气、编程、娱乐、医疗等
输入分类为 `OFF_TOPIC`；与升学有关但超出湖南 2025 本科批当前范围的省份、年份、
升学类型和艺术体育等输入分类为 `OUT_OF_SCOPE`。两者都用简短边界说明、当前能力和
一个继续方向回复，不回答原问题、不创建 run，也不修改画像或旧报告。

明确命令继续由 deterministic 规则处理；没有形成有效动作时，才调用受限 LLM 输出
`EXPLAIN_RESULT / REVISE_PLAN / CLARIFY / OFF_TOPIC / OUT_OF_SCOPE`。模型只做分类，
不能为无关问题生成答案，也不能在非修订分类中返回画像 patch。

安全危机输入优先于业务边界。对自伤、自杀、现实人身危险等表达，先提供简短共情、
立即联系可信赖的人和当地急救/心理援助的建议，并暂停志愿任务推进；不得把此类输入
交给普通意图模型或返回“只能聊志愿”。
