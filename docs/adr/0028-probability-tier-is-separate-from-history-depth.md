# 0028 · 概率分档与历史覆盖深度分离

- 状态：已接受
- 决策者：Francis
- 日期：2026-11-23

ADR-0027 把“历史年数不足”直接转换成降档规则，导致用户分数明显高于某专业组 2024 年录取线时，只因缺少 2022–2023 lineage 就被错误归为冲档。这是把录取风险与证据完整度混为一个概念。

决定恢复按概率阈值决定冲/稳/保：单年强命中仍最高 75%，可以进入稳档；历史只有 1 年时必须作为独立的数据质量提示展示“仅 1 年有效历史、样本有限”，但不能因此把明显领先的候选降为冲档。多年缺失的数据继续显示暂无数据，不插值。

## 后果

- 撤销单年概率 49% 的强制封顶，恢复单年 75%、两年 95%、三年 99% 的样本上限。
- 稳档可能包含单年强命中候选，但推荐卡和完整报告必须明确提示有效历史年数不足。
- 不通过优化排序伪造多年数据；原始 2022–2023 lineage 缺失仍按 UNKNOWN 展示。
- ADR-0028 取代 ADR-0027；ADR-0022 的 0.7 衰减、临界半权重和概率边界继续有效。
