# 0023 · 受控邀请注册、用户名密码与无联系方式认证

- 状态：部分被 ADR-0025、ADR-0026 替代（账户数据导出与用户可见设备管理已移除；其余有效）
- 决策者：Francis

系统面向受控邀请的考生和家长开放，所有规划、报告和志愿草稿均要求登录。账号使用一次性邀请码注册，
以不可修改的用户名和密码登录；注册时生成 10 个一次性恢复码用于重设密码，不收集手机号、邮箱、
真实姓名或出生日期。注册时记录隐私说明版本，并要求用户确认本人已成年或已取得监护人同意。

登录采用服务端可撤销的 HttpOnly Cookie，支持多设备会话；当前设备可退出，默认 30 天不活跃失效、
90 天绝对失效，密码修改或重设时撤销其他设备。V1 不提供用户可见设备列表或单设备撤销。服务端从
登录会话解析账号 ID 并作为 `principal_id` 向下游传递，客户端提交的主体标识不再可信。既有匿名
主体不迁移，也不能通过输入旧主体 ID 认领。

用户名创建后不可修改，允许 4–32 个中英文字母、数字、下划线和短横线，统一 NFC 规范化并按 ASCII
大小写不敏感判重；昵称可选 1–20 个字符，缺省时显示用户名。密码长度为 12–128 个字符并使用
Argon2id 保存；登录按账号与来源地址限流并指数退避，Cookie 同时启用 CSRF 防护。服务端维护会话
有效期与撤销状态，不再采集用于设备列表展示的浏览器摘要，也不持久化 IP。

注册成功后必须展示 10 个一次性恢复码，用户明确确认已复制或下载后才能继续；服务端只保存恢复码
哈希。已登录用户验证当前密码后可以重新生成一组恢复码，并立即作废旧恢复码。密码修改或密码重设
都撤销其他登录会话。账户删除后，规范化用户名只保留不可逆摘要并永久禁止再次注册。

通用隐私协议不提供独立撤销操作，账户删除即终止服务并删除私有资料；敏感资格数据同意可在账户页
单独撤销，之后需要这些字段的新规划 fail closed，既有已生成报告仍可只读查看。原方案中的账户
原始数据 JSON 导出已由 ADR-0025 移除；报告 PDF 导出能力不受影响。

连续 24 个月未登录的账号会删除账号及全部私有资料，只保留不含内容的删除审计；登录页与账户页
必须持续展示该规则。账户页提供明确的退出登录入口，不提供设备管理列表。

如此选择是为了在不保存直接联系方式的前提下完成跨设备访问和私有资源归属，并避免把当前可伪造的
客户端请求头继续当作身份。代价是邀请码由受控运维流程生成，所有恢复码遗失后无法自助找回账号；
系统不建设管理员用户管理页面。

## 后果

- 用户账号及登录会话由 svc-gateway 管理；对话、报告、画像与志愿草稿仍由 svc-orchestrator 管理。
- 邀请码和恢复码只保存不可逆哈希，仅在生成时展示一次。
- 账户删除立即封锁登录与私有读取，并复用现有 principal 数据删除链路删除全部私有规划资料。
- 不活跃清理与账户删除复用同一数据删除链路，并在删除前按版本化保留策略清理相关私有资源。
- ADR-0007 中“固定 URL 直接打开或分享”的报告访问方式不再是目标态，待报告访问方案确认后标记替代关系。
