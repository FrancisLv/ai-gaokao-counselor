# 0024 · 已保存志愿表长期保留，报告仅账号本人登录访问

- 状态：已接受（2026-11-23）
- 决策者：Francis

用户显式保存志愿表后，该草稿及所依赖的不可变正式报告快照在账号存续期间保留，直到用户删除这份
志愿表或删除账号；其他未保存的正式结果、画像和检查点继续按既有 30 天策略清理。删除一份志愿表时，
删除其全部草稿版本并只保留不含内容的删除审计，父正式报告不再受长期保存保护，但仍按普通结果保留期
存在。账户删除始终删除全部私有资料，优先于志愿表保留规则。

“我的志愿表”和报告都只允许所属账号在登录后访问。报告保留不可变的 `result_version` 内容，通过
`/reports/{run_id}` 身份路由读取并在服务端校验所有权；不生成公开固定 URL，也不提供分享 token。
失效或撤销的正式结果仍可从已保存志愿表中只读查看并显示原因，但不得继续修改或导出。

这样选择是为了让用户明确保存的方案可以跨设备长期查看，而不是在 30 天后无故消失；同时避免静态
公开页面或可猜链接泄露分数、选科、地域偏好和志愿顺序。代价是需要让保留清理识别草稿保护关系，
并把报告读取从页面自取参数收紧为账号所有权校验。

“我的志愿表”每份正式结果只展示一条当前项，名称由报考年、科类和批次自动生成，不提供人工命名；
列表按最后保存时间倒序，每页 20 条，并支持按可用状态筛选。历史草稿版本可查看，也可恢复为新版本。

同一对话中生成后续 `REVISE_PLAN` 正式结果后，旧结果的志愿表显示为“已被新方案替代”，仍可只读
查看并跳转到后继方案，但不能继续编辑或生成新 PDF；不同对话中的平行方案互不替代。由此，用户可见
状态分为当前可用、已被新方案替代、已失效和已删除/不可用。“已失效”只表示结果依据不可继续信任，
“已被新方案替代”只表示存在同一修订链中的后继方案。

本决策替代 ADR-0007；不可变结果、确定性内容和浏览器打印 PDF 等其余决策保持有效。
