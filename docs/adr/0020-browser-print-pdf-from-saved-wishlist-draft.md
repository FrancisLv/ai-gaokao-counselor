# 0020 · PDF 志愿报告采用已保存草稿与浏览器原生打印

- 状态：已接受（2026-11-22）
- 决策者：Francis

报告页需要把用户选好的志愿下载为 PDF。PDF 只读取已保存的志愿草稿版本和同一父
`result_version` 的静态推荐报告，不读取页面未保存修改，也不创建新的正式推荐结果；
有未保存修改时先成功保存草稿，再生成 PDF。导出内容是汇总报告，包括方案概况、全部志愿组、
已保存的拟填专业、专业组历史、资格核验、风险提示及 `result_version + release_id + draft_version` 身份，
不附带独立学校详情页，不显示用户姓名、`principal_id` 或 `run_id`。

系统不新增服务端 PDF 渲染链、公开下载 URL 或独立下载权限，而是通过报告页的 A4 纵向打印样式
调用浏览器原生打印，由用户选择“另存为 PDF”。这样可复用同一证据与报告数据，保留可检索中文文本，
避免为个人演示系统引入额外的 PDF 服务与敏感文件存储；代价是实际文件由浏览器生成，排版一致性
依赖打印实现，首版只以桌面 Chrome/Edge 为正式验收目标。

失效、撤销或不可发布的结果不得生成新 PDF；已下载到用户设备上的旧文件无法追溯回收。
导出沿用当前报告访问边界，不新增分享 token。
