# 0026 · 移除用户可见登录设备管理

- 状态：已接受
- 决策者：Francis
- 日期：2026-11-23

项目用于面试演示，用户可见的登录设备列表不是高考志愿决策的核心能力。它增加设备列表、单设备撤销、浏览器摘要展示、proto 契约、前端状态和测试成本，却没有足够的产品价值。我们决定从账户页和 Gateway 对外接口中移除设备管理，但保留 `login_session` 作为认证、过期和撤销机制：当前设备可以退出，密码修改或重设会撤销其他会话。

本决策部分替代 ADR-0023 中“登录设备用于展示的浏览器摘要”和用户可见设备管理部分；多设备登录、Cookie 认证、会话过期和密码变更后的其他会话撤销继续有效。

## 后果

- 删除 `ListLoginSessions`、`RevokeLoginSession` RPC、对应 HTTP 路由、前端调用和测试。
- 新登录会话不再采集 `User-Agent` 摘要；历史 `login_session.user_agent_summary` 列与数据不迁移，保持历史迁移不可变。
- 当前 `v1` 仅服务本仓库受控前端且未承诺外部兼容，因此直接在该版本移除；未来若重新需要设备管理，应按 PRD §7.5 引入新契约版本，并重新评估数据最小化。
