# 0019 · 专业级录取概率独立估计且缺失时为 UNKNOWN

- 状态：已接受（2026-11-22；专业身份约束由 ADR-0021 补充）
- 决策者：Francis

专业级录取概率复用 release 绑定的专业组 lineage 定位历史组，再在每个历史组内仅按同专业
代码匹配 `major_admission`，使用与组级概率一致的 `weighted_hit`、时间衰减和样本上限计算。
有效历史不足时不展示数字，标记为“暂无可可靠估计”，不复制组级概率，也不按名称模糊匹配。

原因是院校专业组概率回答“是否能投进该组”，专业级概率回答“在历史专业录取参考下命中该专业”；
两者口径不同。把组概率复制到每个专业会让用户误以为专业之间没有录取差异。专业代码逐年变化
时，按名称猜测会把不同专业错误合并，违反可复现和宁报错不编数据原则。

代价是专业代码变化、历史断档或新专业只能显示 UNKNOWN，当前可见专业数可能多于可估计概率数。
用户替换或排序拟填专业不会重算专业、组级概率或整表滑档率；这些指标属于已发布推荐结果和
固定 release，而不是用户编辑时的派生状态。
