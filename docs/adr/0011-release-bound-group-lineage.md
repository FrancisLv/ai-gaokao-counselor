# 0011 · 跨年专业组通过 release 绑定 lineage 映射

- 状态：已接受（2026-11-20）
- 决策者：Francis

专业组代码是当年招生代码，不是稳定跨年主键。系统新增
`admission_group_lineage`，把报考年的目标专业组映射到每个历史年份的录取专业组。
映射随 release 固定，并保存匹配方式、置信度、目标/历史专业名称及交集证据。

生成顺序：

1. 同院校代码、同专业组代码优先，记录为 `EXACT_CODE`，置信度 1。
2. 无精确组时，只允许同院校代码、同首选科目，且专业名称集合 Jaccard 重合度不低于
   0.6；记录为 `MAJOR_NAME_JACCARD` 和实际置信度。
3. 多个候选出现同分最高重合度时视为歧义，不建立映射。
4. 历史录取组院校身份不一致时不建立映射。

这样既恢复因专业组重新编号而丢失的多年数据，又避免只按学校或单个专业名称强行拼接。
代价是 lineage 成为 release 数据准备的一部分；缺失或低置信映射仍展示暂无数据。

## 2026-11-21 修订：同代码不代表同专业组

真实数据中发现专业组代码会被学校跨年复用。例如兰州大学 2025 年（110）组是数学、
物理、计算机等理工专业，2024 年（110）组却是临床医学、口腔医学等医学专业，专业
名称重合度为 0；旧规则因代码相同直接接受映射，导致医学组历史线被错误套用到理工组。

自 `group-lineage-v2` 起，专业名称重合度是所有映射的前提：先计算专业名称 Jaccard，
达到 0.6 后才进入候选；专业组代码相同只在最高重合度并列时作为 tie-break。代码相同
但专业不重合时不建立映射，宁缺毋滥。该修订不改变旧报告，重建映射后由新 run 使用。

完整故障与修复过程见
[`docs/postmortems/2026-11-21-lanzhou-group-code-reuse.md`](../postmortems/2026-11-21-lanzhou-group-code-reuse.md)。
