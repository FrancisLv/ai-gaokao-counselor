# 0017 · 精确数据查询使用受控领域查询，不做通用 Text-to-SQL

- 状态：已接受
- 决策者：Francis
- 日期：2026-11-21

V1 不开放通用 Text-to-SQL，即不允许 LLM 在运行期针对业务库生成并执行任意 SQL。
“我不想去北方读大学”这类输入需要先把自然语言归一为受控画像字段或领域查询意图，
不是 SQL 生成问题。精确分数、计划、规则和派生数值继续由 `svc-algo` 或其他领域读取
接口使用已发布 `release_id`、参数化查询和固定字段完成。

## 后果

- LLM 只能提出受限画像 patch、结构化查询意图或文案，不能直接访问 SQL 或修改候选、
  概率与资格结论。
- 缺少精确数据查询能力时，应增加可测试、可版本化的领域查询契约，而不是让模型临时
  拼接表名、连接条件或聚合逻辑。
- 大区、模糊偏好和专业方向必须先澄清为受控字段；未确认的语义不得通过模型生成的
  SQL 变成硬筛选或事实结论。
- 原始 SQL 只存在于服务端受审代码中，并遵守字段 allowlist、访问范围、`release_id`
  与参数化约束；查询结果仍须进入对应的结构化证据与验证链路。
