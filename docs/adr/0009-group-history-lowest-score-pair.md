# 0009 · 专业组历史最低分与位次取同一条记录

- 状态：已接受（2026-11-20）
- 决策者：Francis

专业级录取明细没有官方组投档线字段。为避免把组内最强专业的位次误当成
“最低录取位次”，同一院校代码、专业组代码和年份内按
`min_score ASC, min_rank DESC, major_code ASC` 选择一条记录，同时作为
“专业组最低录取分”和“最低位次”的参考来源；概率模型的组线百分位也使用这条
记录的位次。

旧实现使用 `MIN(min_rank)`，实际会选到高分组内最强专业的位次。以中南大学
（107）2024 年为例，旧口径得到 641 分专业对应的 3439 名，而组内最低录取分为
624 分、同条记录位次为 6798 名。修正后用户看到的历史表及概率输入使用同一口径。

该数据仍不是考试院发布的官方专业组投档线；报告必须保留“历史录取参考”的命名，
缺失年份显示暂无数据，不插值，也不宣称录取保证。
