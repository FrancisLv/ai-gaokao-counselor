# 0018 · 用户选专业保存为独立版本化志愿草稿

- 状态：已接受（2026-11-22）
- 决策者：Francis

正式推荐报告发布后保持不可变。用户在每个院校专业组内选择、替换或排序至多 6 个拟填专业时，
系统把它保存为绑定父 `result_version`、`release_id`、专业组和专业代码的独立志愿草稿；
草稿采用显式保存和版本冲突保护，不原地修改报告。

这样选择是因为“选择已有专业组中的哪些专业”不改变专业组身份、组级录取概率、冲稳保配比
或整表滑档率，也没有产生新的画像筛选条件。若每次操作都创建 `REVISE_PLAN`，会无意义地
重新确认画像、生成候选和报告；若只保存在浏览器，又无法跨设备恢复且丢失审计身份。

代价是需要新增草稿存储、读取和并发接口，并在保存时重新校验报考年计划归属、资格状态、
每组 1–6 个专业和专业不重复。草稿不是新的正式推荐结果；推荐版本或 release 失效时，
草稿必须标记为不可保存，并提示基于最新结果重新生成。

历史草稿版本默认只读；用户选择恢复某个历史版本时，系统复制其选择保存为新的
`draft_version`，既有版本保持不变。这样恢复操作也可审计，并继续使用显式版本冲突保护。
