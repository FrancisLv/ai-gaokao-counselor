# 0007 · 推荐结果采用不可变静态 HTML 报告

- 状态：已被 [ADR-0024](0024-authenticated-report-and-saved-wishlist-retention.md) 替代（2026-11-23）
- 决策者：Francis

推荐结果由已发布的 `result_version` 生成一个不可变报告汇总页和每所推荐学校的详情页，使用固定 URL 直接打开或分享，而不是依赖登录后再次查询 API 动态渲染。当前项目是个人面试演示，静态 HTML 能以更低复杂度展示完整推荐、证据出处与风险提示，同时保留与正式结果版本的一一对应关系；代价是筛选和个性化交互能力有限，若未来需要实时筛选或登录权限，再演进为服务端动态报告。
