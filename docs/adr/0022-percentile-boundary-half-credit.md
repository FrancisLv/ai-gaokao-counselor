# 0022 · 概率改用原始百分位与临界半权重

- 状态：已接受（2026-11-23）
- 决策者：Francis

计划数变化不再数值修正历史录取百分位。概率直接比较用户当前百分位与各历史年份的
`最低位次 / 当年同科类总人数`；相差不超过 0.2 个百分点的年份标记为临界，记 0.5 个
命中权重，超出临界区后才分别记 1 或 0。继续使用 0.7 年际衰减、样本年数封顶和
1%–99% 输出边界。

这样避免了计划修正把所有年份统一缩放造成的临界翻转，也避免几名的百分位差让概率从
32% 跳到 78%。计划数变化仍会在报告中展示为风险提示，但不再改变数值概率。代价是
模型不再尝试预测计划增减对录取线的影响，实际难度变化只能由用户结合提示和当年章程判断。
