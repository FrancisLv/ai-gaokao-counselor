# 0030 · 志愿草稿支持专业组级移出、重新加入与重排

- 状态：已接受（2026-11-23）
- 决策者：Francis

正式推荐结果继续不可变，45 个院校专业组是用户志愿表上限，不是系统必须填满的目标。用户可以从
本次正式报告推荐的组中移出不要的组、重新加入已移出的组并调整组顺序；被移出的组进入“未纳入
志愿表的推荐专业组”，仍可在正式报告中查看和恢复。用户只能加入本次正式报告中的组，单次移出
不自动形成画像偏好；需要改变未来推荐范围时应创建独立的 `REVISE_PLAN`。

已保存志愿草稿包含 1–45 个拟填院校专业组，每组包含 1–6 个资格 PASS 的拟填专业。专业组集合
或顺序发生变化后，系统使用各组原有且已验证的录取概率，由确定性代码重新计算草稿层专业组数量、
冲稳保数量、滑档率和期望满意度。正式报告、组级概率和专业级概率保持不变，草稿风险摘要不能
冒充正式报告结论。低于保底目标或出现其他风险时允许显式保存并告警，不能伪报为安全，也不能
自动补回用户移出的组。

这样选择是因为用户最终提交的组集合和顺序才是其真实意愿；强制覆盖全部系统推荐等于替用户
表达接受，而为了让用户少选几组就重新确认画像并运行 `REVISE_PLAN` 也没有必要。PDF 继续只使用
最新已保存草稿，静态正式报告则保留完整推荐和未纳入组列表；页面未保存的修改不进入 PDF。

该决策扩展而非替代 ADR-0018：ADR-0018 中“组内专业选择不改变整表风险”继续成立；本 ADR 只新增
专业组集合变化所产生的草稿层风险摘要。代价是草稿保存契约必须允许正式报告候选的非空子集
（可以等于全集）并保留
用户组顺序，报告页需要同时表达正式候选与当前草稿。该能力已于 2026-11-23 接入
`SummarizeWishlistDraft`、迁移 55 与报告页专业组级操作。
