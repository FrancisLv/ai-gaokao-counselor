# 志愿算法设计：位次 → 概率 → 冲稳保 → 志愿表

> svc-algo 的核心算法设计。原则：**全部确定性、可复现、可审计**——数值由算法给，人话解释由 LLM 写。
> 对应代码：`internal/algo/{rank,prob,constraint,optimize,sim}`。

---

## 0. 总览：四步流水线

```
① 位次可比化         ② 录取概率          ③ 效用打分         ④ 列表优化
  分数→位次→百分位  →  历史位次分布 → P   →  偏好 → U_j   →  选哪些 + 排序
                                                   ↑
                                        ⑤ 投档模拟 / 蒙特卡洛 校验滑档率与 E[U]
```

**关键直觉**：跨年会变的量（总分、报考人数）都不能直接用。真正可比的是**位次百分位**。

---

## 1. 记号与约定

| 符号 | 含义 |
|------|------|
| `r_u` | 用户位次（越小越好；1 最优） |
| `T(p,y,t)` | 该省 `p`、年 `y`、科类 `t` 的考生总数（取自一分一段表末行累计人数） |
| `q_u = r_u / T` | 用户**位次百分位**（越小越好） |
| `g` | 一个「院校专业组 / 专业」（候选单位） |
| `R_i` | `g` 在第 `i` 年的**最低录取位次** |
| `N_i` | `g` 在第 `i` 年的**招生计划数** |
| `q_i = R_i / T(p, y_i, t)` | `g` 第 `i` 年的**录取位次百分位** |
| `P_j` | 候选 `j` 的录取概率 |
| `U_j` | 候选 `j` 的效用（用户偏好打分） |
| `L` | 该省可填志愿数上限（山东 96 / 江苏 40 / 浙江 80 … **以本省规则为准**） |

**录取判据**：你的位次 ≤ 校线位次 ⇔ `q_u ≤ q_g`。即**你比"该校最低录取者"更好**就会被录取。

---

## 2. ① 位次可比化（`rank`）

**分数 → 位次**：查一分一段表，落在某分段就取该分段的累计人数（=最差名次，保守）；表里没有该分数就在相邻分段间**线性插值**。

**位次 → 百分位**（跨年可比的核心）：

```
q_u = r_u / T(p, y_next, t)          # y_next 用最近年份总人数或趋势外推
q_i = R_i / T(p, y_i, t)             # 每个历史年份各自归一化
```

**为什么用百分位而不是裸位次 / 线差**：

| 方法 | 问题 |
|------|------|
| 直接用位次 | 报考人数逐年变，位次不可比 |
| 线差法（分数−批次线） | 批次合并后失效，且不同年份难度不同 |
| **位次百分位（采用）** | 消除了"总人数/难度"的年际差异，最稳 |

> 边界：新高考首年、批次合并年 → 历史不可比，需**放大置信区间或标注"依据不足"**。

---

## 3. ② 录取概率估计（`prob`）

### 3.1 样本与加权

对候选 `g`，取最近 `n` 年（默认 5 年）的 `q_i` 作为样本，做**时效加权**：

```
w_i = λ^(age_i)                      # λ=0.7；越近的年份权重越大
若已知次年计划数 N_next：
    s_i = N_next / N_i                # 招生计划变化因子
    调整样本：q_i' = q_i · (s_i)^β    # β=0.5；计划扩招 → 校线位次变大(更易)
```

### 3.2 分布估计（按样本量选方法）

**要算的是** `P = P(q_g ≥ q_u)`（校线百分位不差于你）。`n` 为有效样本数：

- **n ≥ 5：正态近似**
  ```
  μ = Σ w_i q_i / Σ w_i ;  σ = sqrt( Σ w_i (q_i−μ)² / Σ w_i )
  z = (q_u − μ) / σ
  P = 1 − Φ(z)
  ```
- **n ≥ 5 且疑似多峰：核密度（KDE）**
  ```
  P = 1 − KDE_CDF(q_u)
  ```
- **1 ≤ n < 5：经验加权**
  ```
  P = Σ w_i · [q_i ≥ q_u] / Σ w_i      # 历史上"够得着"的年份占比
  ```

### 3.3 趋势修正（可选）

对 `q_i` 关于年份做线性拟合，外推一年得到 `μ'`，替换 `μ`——用于捕捉某校**持续变热/变冷**。

### 3.4 输出（必须可审计）

```
prob        : 0~1
ci          : 置信区间（由 σ 或 bootstrap 得到）
basis       : { n, years[], method, weights, adjusted: bool }
band        : 见 §5
```

> **纪律**：`n == 0` 或无可靠数据 → 返回 `ErrNoReliableData`，**宁可说"依据不足"，绝不编造概率**。

---

## 4. ③ 效用函数（`U_j`，确定性）

`U_j` 是用户对候选 `g` 的偏好打分，`[0,1]`。由**结构化偏好 + 院校属性**确定：

```
U_j = Σ_k α_k · s_k(g)          # α 为用户权重，Σα=1
```

| 维度 k | 说明 | 数据来源 |
|--------|------|----------|
| 学校层次 | 985/211/双一流/学科评估 | 院校库 |
| 专业匹配 | 兴趣专业 vs 该专业（语义映射由 LLM 产出标签，打分为确定性） | 画像 + 专业库 |
| 地域匹配 | 离家近 / 目标城市 | 画像 + 院校所在省 |
| 就业/升学 | 就业率、保研率（可选） | 院校库 |
| 风险偏好 | 冲稳保倾向，影响 α 分布 | 画像 |

> `α_k` 可由 LLM 从自然语言偏好抽取（语义），但**打分公式是确定性的**——满足"LLM 管语义、算法管数值"。

---

## 5. ④ 冲稳保分档（banding）

按概率 `P` 分档（默认阈值，可调）：

| 档 | 概率区间 | 含义 |
|----|----------|------|
| 垫 | `P < 0.20` | 风险过高，一般不建议（可少量尝试） |
| **冲** | `0.20 ≤ P < 0.50` | 有一定希望，搏一搏 |
| **稳** | `0.50 ≤ P < 0.80` | 大概率能录 |
| **保** | `P ≥ 0.80` | 兜底，确保不滑档 |

---

## 6. ⑤ 志愿表优化（`optimize`）

### 6.1 平行志愿的结果模型（关键）

平行志愿规则是「**分数优先、遵循志愿**」：按位次逐一投档，投到你时按你填的顺序扫描，**投进第一个"还有名额"的院校**。

于是给定一个按顺序的志愿表，你的结果 = **第一个录取你的院校**：

- 落在第 k 个的概率：`P_(k) · Π_{i<k}(1 − P_(i))`
- **滑档**概率：`Π_i (1 − P_(i))`

### 6.2 目标函数

等价于最大化"你最终会去的那所学校的期望效用"：

```
E[U] = Σ_k U_(k) · P_(k) · Π_{i<k}(1 − P_(i))  +  U_slip · Π_all(1 − P_(i))
```

`U_slip` = 滑档结果（复读/无学可上）的效用，取最小值。

### 6.3 排序 = 偏好序（可证明）

因为"更靠前 = 更高优先级"，且录取后不再看后面的志愿：
**把 `U` 更高的排在前面是占优的**（把低 `U` 放前面只会"截胡"高 `U`）。
→ **排序固定为 `U` 降序**；真正的决策是「**选哪些进来**」。

### 6.4 选择：贪心 + 局部搜索

- **加入任一候选不会变差**（它是"后来的兜底"，`U_j ≥ U_slip`），所以尽量填满 `L`。
- 但"填哪个"要看**边际贡献**：在高 `U` 低 `P` 与 低 `U` 高 `P` 之间权衡。
- **贪心**：每次把"边际 `E[U]` 增量最大"的候选插入其 `U` 序位置，直到 `L`。
- **局部搜索**：两两交换 / 替换候选，迭代改进 `E[U]`，全程**确定性**（固定种子或纯确定性比较）。

### 6.5 约束（硬 / 软）

| 约束 | 类型 | 说明 |
|------|------|------|
| 志愿数 ≤ `L` | 硬 | 以本省规则为准 |
| 兜底：`保` 档 ≥ `B_min`（默认 `max(3, 20%·L)`） | 硬 | 防滑档的底线 |
| 选科 / 单科 / 体检 / 批次 | 硬 | **已在 `constraint` 层剔除**，此处不再放宽 |
| 冲稳保配比（默认 冲 30% / 稳 40% / 保 30%） | 软 | 偏离施加惩罚 |
| 梯度平滑（`P` 大体递增、避免倒挂/扎堆） | 软 | 惩罚相邻难度跳变 |

实现：**约束满足 + 启发式（贪心 + 局部搜索）**——先用贪心满足硬约束，再局部搜索优化 `E[U]` 与软约束。

---

## 7. ⑥ 投档模拟 / 蒙特卡洛校验（`sim`）

**确定性模拟**：用历史校线，按投档规则把志愿表模拟投一遍 → 是否滑档、落在哪个志愿。

**蒙特卡洛**（把 `prob` 和 `sim` 串起来）：

```
repeat N 次（默认 2000）:
    对每个候选 j，从它 §3 的分布里采样一个校线 q_j
    按位次投档，得到"落在第几个 / 滑档"
估计: P_slip = 滑档频率;  È[U] = 效用均值
```

用途：
- 校验 §6.2 的解析 `E[U]`；
- 给出**滑档风险**（面试/报告里的关键数字）；
- 敏感性分析（某个"保"不稳时，整体滑档率上升多少）。

## 8. 参数默认值与调参

| 参数 | 默认 | 说明 |
|------|------|------|
| 历史窗口 `n` | 5 年 | 太少不稳、太多过时 |
| 时效衰减 `λ` | 0.7 | 越近权重越大 |
| 计划修正 `β` | 0.5 | 招生计划变化的影响强度 |
| 分档阈值 | 冲 .20 / 稳 .50 / 保 .80 | 可随省份/年份调 |
| 兜底数 `B_min` | `max(3, 20%·L)` | 防滑档 |
| 配比 | 冲30/稳40/保30 | 软约束 |
| 蒙特卡洛 `N` | 2000 | 精度 vs 耗时 |

---

## 9. 边界与降级

| 情况 | 处理 |
|------|------|
| 无历史数据 | `ErrNoReliableData`，不推荐该候选 |
| 样本 `n=1` | 置信区间极宽，标"高风险"；不单独作保底 |
| 政策变化（批次合并 / 首年新高考） | 历史不可比 → 放大 CI / 标"依据不足" |
| 招生计划剧变 | 用 `β` 修正，并降置信 |
| 全部候选中不到 `B_min` 个"保" | 放宽地域/专业偏好，或明确告知"保底不足" |
