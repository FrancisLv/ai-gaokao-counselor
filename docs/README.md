# docs

项目文档导航。架构描述目标，开发指南与验收记录描述当前实际能力。

建议阅读顺序：

1. [开发指南](development-guide.md)：系统边界、模块完成度、数据流、配置、运行与测试。
2. [算法通俗说明](algorithms.md)：设计动机与局限，不作为参数默认值来源。
3. [task2 实施文档](task2-implementation-plan.md)：algo 数据结构、算法细节、接口、错误码及验收状态。
4. [开发问题与验收记录](dev-log.md)：历史问题、修复证据、覆盖率和性能实测。
5. [架构设计](agent-architecture.html)：完整目标拓扑与后续业务设计，并非当前实现清单。
6. [设计问题决策索引](task2-review-todo.md)：Q 系列讨论结论与决策背景。

[根 README](../README.md) 提供最短构建入口；[招生章程目录](charters/) 保存本地语料。本轮仅只读解析验证，未重新生成数据库中的向量。
